MEDCID Planner — Versão corrigida

COMPUTADOR
1. Clique com o botão direito no ZIP e escolha "Extrair tudo".
2. Abra a pasta extraída.
3. Dê duplo clique em ABRIR_AQUI.html ou index.html.
4. Se o navegador bloquear, clique com o botão direito em index.html > Abrir com > Chrome/Edge.

ANDROID
1. Extraia o ZIP no celular.
2. Abra index.html com Chrome.
3. Para virar app instalável de verdade, hospede a pasta no GitHub Pages/Netlify e abra o link no Chrome > três pontinhos > Adicionar à tela inicial / Instalar app.

IPHONE/IPAD
1. O iOS não lida tão bem com site local em HTML.
2. Melhor caminho: hospedar a pasta e abrir pelo Safari.
3. Safari > Compartilhar > Adicionar à Tela de Início.

IMPORTANTE
- Não tente abrir o index.html ainda dentro do ZIP. Extraia primeiro.
- Seus dados ficam salvos no navegador do aparelho.
- Use o botão Backup para levar seus dados para outro celular/computador.
- A rotação de tela funciona se a rotação automática do aparelho estiver ativada.
